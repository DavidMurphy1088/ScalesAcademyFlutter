The presence of the kb in Apple Settings only means the device can do bluetooth audio, not MIDI

Setup on MAC

- No MIDI device at all.
  Audio MIDI Setup -> Show Audio Devices -> Make sure phone (iPad) is disabled
  MIDI Studio -> Configure Network Driver -> session not Enabled
  MIDI Studio -> Configure Bluetooth -> not advertising (Stop Advertising)

- A connected (cabled, USB) MIDI device. Detected at app start and when running.
  Audio MIDI Setup -> Show Audio Devices -> Make sure phone (iPad) is enabled
  VMPK Edit -> MIDI Connections -> output driver CoreMIDI, output set to iPhone
  Listen with = Microphone -> "MIDI Piano Detected" alert at start.
  Listen with = MIDI piano -> used automatically, no alert.

- A Bluetooth MIDI device. Detected at app start and when running.
  Kill Audio MIDI Setup and run BlueTooth (BMK) app on iPad. Download is called midimttr. Tell it to advertise its MIDI service
  Note that even when midimttr is closed the connection lingers. Go to iPad Setting and restart BlueTooth
